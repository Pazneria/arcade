MPFB human sample - integration handoff

File: mpfb-neutral-adult.glb (glTF binary, self-contained; no external textures)
Created with MPFB 2.0.18 on Blender 5.2.0. The MPFB core base mesh and targets are CC0: https://static.makehumancommunity.org/mpfb/faq/use_in_closed_source.html
MPFB extension code is GPL-3.0-or-later; the extension itself is not included in the GLB.
The simple opaque shirt, trousers and shoe surfaces and solid materials were generated for this sample. No third-party clothing or textures were downloaded.
Height: 1.75 m; feet approximately at origin. glTF uses its standard Y-up convention. Static A-pose; no armature or animations.
Four meshes: body and three close-fitting garment surfaces, four solid-color materials. This is a rough visual scale/sample, not production clothing: bald, untextured, no separate eyes, and garment seams are approximate.
preview.png is an isolated Blender render; it is not an in-game screenshot. Verify scale, lighting, ground contact, appearance and renderer support in the target Alcatraz build before integration. No game project was edited.
