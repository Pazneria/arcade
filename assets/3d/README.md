# 3D Assets

This folder separates generated source assets from runtime-ready assets.

- `source/`: raw AI-generated GLBs, prompts, concept images, and provenance notes
- `runtime/`: cleaned and optimized `.glb` or `.gltf` files loaded by the app
- `previews/`: thumbnails, icons, and review renders generated from cleaned models

See `docs/3d-asset-workflow.md` before adding or replacing 3D assets.
